# CC Realtime Translator

โปรแกรมจับภาพเฉพาะ "กรอบ" บนหน้าจอที่แสดงคำบรรยาย (CC) จาก Zoom / Microsoft Teams
แล้วอ่านข้อความด้วย OCR และแปลภาษาแบบเกือบเรียลไทม์ แสดงผลเป็นแถบซับไตเติลลอย
บนหน้าจอ **ไม่มีการเข้าร่วมประชุมหรือเชื่อมต่อ API ของ Zoom/Teams ใดๆ** — เป็นการ
แคปภาพหน้าจอซ้ำๆ ในบริเวณที่คุณเลือกเองเท่านั้น

## วิธีใช้งานโดยสรุป

1. เปิด CC (Live Transcript / Captions) ในตัว Zoom หรือ Teams ให้ขึ้นบนหน้าจอก่อน
2. รันโปรแกรมนี้ กด "เลือกกรอบ" แล้วลากกรอบครอบตำแหน่งที่ตัวอักษร CC ปรากฏ
3. กด "ทดสอบอ่าน" เพื่อเช็คว่ากรอบ/OCR/การแปลใช้งานได้จริงก่อน
4. เลือกภาษาของ CC, ภาษาที่จะแปลเป็น และเลือกผู้ให้บริการแปล (engine)
5. กด "▶ เริ่มทำงาน" จะมีแถบคำแปลลอยขึ้นกลางล่างจอ — **ลากย้ายตำแหน่งได้จากทุกจุด
   ของกล่อง และลากมุมขวาล่าง (◢) เพื่อปรับขนาดได้อิสระ**

## การติดตั้ง (ทำครั้งเดียว)

### 1. ติดตั้ง Python และไลบรารี
ต้องมี Python 3.9 ขึ้นไป จากนั้น:
```
pip install -r requirements.txt
```
(แนะนำให้สร้าง virtual environment แยกก่อน เพื่อไม่ให้ปนกับไลบรารีอื่นในเครื่อง)

### 2. ติดตั้งโปรแกรม Tesseract OCR (จำเป็น แยกจาก pip)
`pytesseract` เป็นเพียงตัวเชื่อมไปยังโปรแกรม Tesseract OCR ที่ต้องติดตั้งแยกต่างหาก:

- **Windows**: ดาวน์โหลดตัวติดตั้งจาก https://github.com/UB-Mannheim/tesseract/wiki
  (ระหว่างติดตั้งเลือกภาษาเพิ่มเติมที่ต้องใช้ด้วย เช่น Thai)
  ค่าเริ่มต้นโปรแกรมนี้จะมองหาไฟล์ที่ `C:\Program Files\Tesseract-OCR\tesseract.exe`
  ถ้าคุณติดตั้งไว้ที่อื่น ให้แก้พาธในไฟล์ `cc_realtime_translator.py` ตรงคอมเมนต์
  `pytesseract.pytesseract.tesseract_cmd = ...`
- **macOS**: `brew install tesseract tesseract-lang`
- **Ubuntu/Debian**: `sudo apt install tesseract-ocr tesseract-ocr-tha tesseract-ocr-eng`

### 3. (ถ้าจะใช้ DeepL หรือ Gemini) สร้างไฟล์ .env
สร้างไฟล์ชื่อ `.env` ไว้ในโฟลเดอร์เดียวกับ `cc_realtime_translator.py` ใส่เนื้อหา:
```
DEEPL_API_KEY=your_deepl_key_here
GEMINI_API_KEY=your_gemini_key_here
```
ใส่แค่ตัวที่จะใช้ก็ได้ ไม่จำเป็นต้องมีทั้งคู่ ถ้าไม่ตั้งค่าไว้ โปรแกรมจะบอกในหน้าจอ
เองว่ายังไม่ได้ตั้งค่า (ปุ่ม "ทดสอบ API" จะช่วยเช็คให้ก่อนเริ่มใช้จริง)

- ขอ DeepL API Key ได้ที่ https://www.deepl.com/pro-api (มีแผนฟรีให้ทดลอง)
- ขอ Gemini API Key ได้ที่ https://aistudio.google.com/apikey (มีแผนฟรีให้ทดลอง)

### 4. รันโปรแกรม
```
python cc_realtime_translator.py
```

## ผู้ให้บริการแปล (Engine) ที่เลือกได้

| Engine | ต้องมี API Key | หมายเหตุ |
|---|---|---|
| Google (ฟรี) | ไม่ต้อง | โควตาต่ำมาก (ไม่เป็นทางการ) เจอ rate limit ได้บ่อยถ้าใช้ถี่ |
| MyMemory (ฟรี) | ไม่ต้อง | โควตาแยกจาก Google ใช้เป็นตัวสำรองได้ |
| DeepL | ต้อง | คุณภาพการแปลดี รองรับไทยแบบ early access |
| Gemini | ต้อง | ใช้ AI ช่วยแปล พยายามรักษา label ชื่อผู้พูดที่ OCR อ่านได้ให้ด้วย |

**สำคัญ:** โควตาที่เจอ error "too many requests" เป็นโควตาของขั้นตอน**แปลภาษา**
เท่านั้น (เช่น Google Translate ฟรี) **ไม่ใช่ของ OCR** — Tesseract OCR ทำงานในเครื่อง
ล้วนๆ ไม่มีโควตาใดๆ ถ้าเจอปัญหานี้บ่อย แนะนำสลับไปใช้ DeepL หรือ Gemini แทน

## เกี่ยวกับคีย์ลัดฉุกเฉิน (Force capture hotkey)

ค่าเริ่มต้นคือ `ctrl+shift+t` กดเมื่อไหร่จะบังคับให้อ่านหน้าจอทันทีโดยไม่ต้องรอ
รอบเวลา ถ้าในโปรแกรมขึ้นข้อความเตือนสีเหลืองว่าคีย์ลัดยังไม่ทำงาน ให้ลอง:

- **Windows**: ปิดโปรแกรม แล้วคลิกขวาที่ตัวรัน (หรือ Terminal/Command Prompt)
  เลือก **"Run as administrator"** แล้วรันใหม่ — ไลบรารี `keyboard` ต้องการสิทธิ์นี้
  ถึงจะดักคีย์ลัดได้ทั้งระบบ (ไม่ใช่แค่ตอนโฟกัสอยู่ที่หน้าต่างโปรแกรม)
- **macOS**: ต้องให้สิทธิ์ Accessibility กับ Terminal/IDE ที่ใช้รัน ใน
  System Settings → Privacy & Security → Accessibility

## เคล็ดลับให้ OCR อ่านแม่นขึ้น

- เลือกกรอบให้ **แคบพอดีตัวอักษร CC เท่านั้น** อย่าครอบภาพวิดีโอ/ไอคอน avatar
  วงกลมเข้าไปด้วย ไอคอนวงกลมมักถูก OCR อ่านผิดเป็นสัญลักษณ์แปลกๆ (`@`, `®`, `|`)
  ซึ่งโปรแกรมจะพยายามกรองให้อัตโนมัติอยู่แล้ว แต่เลี่ยงได้ยิ่งดี
- ถ้าอยากให้ขึ้นชื่อคนพูด ต้องเป็น**ชื่อที่เป็นตัวอักษรจริง** อยู่ในกรอบด้วย
  (ไอคอนวงกลมตัวย่อชื่อเป็นรูปภาพ OCR อ่านไม่ได้)
- ปรับ "ความเร็วอ่านจอ" ให้เร็วขึ้นถ้าอยากได้ผลไวขึ้น แต่จะกิน CPU และมีโอกาส
  ชนโควตาแปลมากขึ้นตามไปด้วย

## ข้อจำกัดที่ควรทราบ

- ความแม่นยำขึ้นอยู่กับคุณภาพของ OCR (Tesseract) และคุณภาพของกรอบที่เลือก
- แถบคำบรรยายลอยและกรอบเลือกพื้นที่เป็นหน้าต่างแบบเรียบ (ไม่ปัดมุมโค้ง) โดยตั้งใจ
  เพื่อความเสถียรข้ามแพลตฟอร์ม ส่วนหน้าต่างควบคุมหลักใช้ดีไซน์การ์ดโค้งมนแบบโมเดิร์น
- เป็นการอ่านค่าจากภาพหน้าจอเท่านั้น ไม่ใช่การถอดเสียงพูดโดยตรง
